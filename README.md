# Лабораторная работа № 1 — Web-программирование

Установка и настройка среды разработки и исполнения Web-приложения.

## Материалы

- `config/server.xml` — итоговая конфигурация Tomcat, HTTP-порт 8084.
- `config/server-8080.xml` — конфигурация первой проверки на IPv6 ::1:8080.
- `screenshots/` — снимки Tomcat, Eclipse и Maven.
- `REPRODUCE.txt` — инструкция по воспроизведению.

[Скачать проект ZIP](https://github.com/ssourse/lab1/archive/refs/heads/main.zip)

## Проверенная среда

Java 21.0.8, Tomcat 9.0.112, Eclipse JEE 2025-09, Maven 3.9.11. Выполнение и снимки — Linux.

Проверены два HTTP-порта, запуск и остановка Tomcat из Eclipse, команда mvn -v и выбор внешней установки Maven в Eclipse.

Работа № 1 посвящена настройке среды; отдельное Web-приложение на этом этапе не создаётся. Адреса localhost в материалах предназначены для проверки на своём компьютере.
